CPU Performance

Clock Speed The speed a processor operates is known as clock speed. This is the number of cycles per second, measured in Hertz (Hz) Or more complicated, the rate at which the electrical current changes in the actual circuits. But that's OTT to know. Everything the processor does occurs on the 'tick' of the clock. Clock speed is measured in GHz: Gigahertz, so that is a billion little ticks every single second, with modern devices rarely below 2 GHz! Although, this is not the only thing that can affect the speed of a system, and other things can bottleneck the speed.

Cache Memory Computers improve their speeds with a small amount of cache, which is fast (costly) memory where frequently used instructions or data can be stored temporarily. Because it is temporary and when the device is shut down, this is cleared, it is known as ✨ volatile ✨ memory. In terms of physical location, it is positioned between the main memory and CPU, making it even even faster than main memory. And as such CPU performance goes up! Although, if the required info is not in the cache, it still has to be obtained from RAM (Random Access Memory). A typical PC will have around 16 GB of RAM, or more recently 8 GB (due to the RAM crisis pioneered by AI data centres, so is a good thing I'm not vibe coding any of this), And yet only 2 MB of cache. That is about 6000 times more RAM (assuming the average of that: 12 GB RAM)! But there are also levels of cache, just like there are levels in my game Martian Mike! Level 1 Cache is extremely fast but small (2-64 KB), And, Level 2 Cache is fast, much faster than RAM, but slower than level 1 and is often 256KB-2MB And on rare occasion, CPUs may have Level 3 Data Cache.

Number of Cores Chances are, if you have more common knowledge than me, you'll've heard of dual-core and quad-core. A dual-core processor has two processing units contained within the CPU, a quad-core has four, and so on. And with more than 1 core, the one, the only... the amazing Spiderman ✨ parallel processing ✨ can occur, Letting two or four instructions being executed simultaneously as per the amount of cores.
