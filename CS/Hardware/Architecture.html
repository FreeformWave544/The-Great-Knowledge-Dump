CPU All computer systems must have a Central Processing Unit (CPU) / processor. There are 2 main types of devices:
  • Input Devices
    • These take real world data, such as keyboard clicks or mouse movements, and convert it into a computerised form.
  • Output Devices
    • Inputs are processed, and the computer system will generate outputs.
    • These outputs are via output devices, such as
      • A computer screen,
      • The speaker that produces sound on a phone,
      • Or even an actuator that controls a greenhouse window.
To hold these inputs or instructions currently being executed and data being actively used, A computer need to have memory. More specifically, primary storage. Any computer will have the above 4 basic components (CPU, input device, output device, and primary storage). But very often, a computer will have an optional secondary storage, which is primarily used for storing data.

Von Neumann Architecture With limitations of the very first computers, it was not possible to store programs, And programs were generally input by setting switches. That was until John Von Neumann developed the concept of the stored program computer in the 1940s. This architecture used the idea of holding both programs AND data in memory. Data would then move between the memory unit and the processor.

Common CPU Components The CPU of a computer is the hardware which executes programs while managing the rest of the hardware. It is easy to think of the CPU as the brain of the computer. Just as your brain contains parts that remember things, parts that think , and parts that make the rest of your body operate, The PU does the same for the computer. Computers also, often contain main memory and cache (said "cash") memory. The cache is very fast memory, very close to the CPU, used to hold temporary instructions or data for quick access. This type of memory is volatile, meaning it is non-permanent, and gets cleared when the computer shuts down.

FDE Cycle The Fetch-Decode-Execute cycle (FDE cycle) does what its name says. The CPU fetches an instruction from main memory, decodes the instruction, then executes the instruction. The amount of times this cycle executes per second is measured in Hertz (Hz). And if we dive deeper into the CPU, we find out that it contains the Control Unit (CU) and Arithmetic Logic Unit (ALU), as well as some registers.

Control Unit This coordinates all of the activities taking place inside of the CPU, with its functions summarised:
  • Controls the execution of instructions in the correct sequence.
  • It decodes instructions (part of the FDE cycle).
  • Regulates and controls processor timing using regular pulses from the system clock.
  • Sends & receives control signals to and from other devices within the computer.

Arithmetic Logic Unit The Arithmetic Logic Unit has 3 main functions:
  • Logical Operations
    • These include `AND`, `OR`, and `NOT`
  • Shift Operations
    • The bits in a computer word can be shifted left/right a certain number of places. The ALU handles this.
  • Arithmetic Operations
    • These include addition, subtraction, multiplication, and division.

Special-Purpose Registers A register in and of itself is defined as a special, VERY fast memory location contained within the CPU, typically executing instructions. The CPU has a number of these registers that are for a special-purpose. These are:
  • Memory Address Register (MAR)
    • Hold the address of the instruction/data to be fetched/stored.
  • Memory Data Register (MDR)
    • Holds the data/program instruction temporarily when it is fetched from/sent to memory.
  • Program Counter (PC)
    • Holds the memory address of the next instruction to be processed.
  • Accumulator (ACC)
    • Results of operations carried out in the ALU are temporarily stored in this special-purpose memory location.
