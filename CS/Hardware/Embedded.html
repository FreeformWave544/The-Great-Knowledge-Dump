Embedded Systems

An embedded system is a small computer built into a piece of equipment, designed to perform a specific function.

Characteristics of an Embedded System Reliability and minimal resources are the main characteristics. The program which controls the equipment is held in ROM, and as such cannot be altered. It has a very limited OS to minimise memory usage, but is only able to run a single application. It has a very simple UI (User Interface), e.g. the buttons of a microwave or washing machine, and many have no UI whatsoever. While others have sensors to measure external stimuli and react accordingly.
